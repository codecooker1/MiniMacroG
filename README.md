MiniMicroG is a cute little macropad made following the [HackPad](https://blueprint.hackclub.com/starter-projects/hackpad) starter guide in Blueprint.

Used Components:
- Seeed XIAO RP2040 (x1)
- Through-hole 1N4148 Diodes (x6)
- MX-Style Switch (x6)
- EC11 Rotary Encoder (x1)
- 0.91 inch OLED display (x1)
- SK6812 MINI-E LED (x6)
- Blank DSA keycaps (x6)
- M3x16mm screws (x4)
- M3x5mx4mm heatset inserts (x4)
- 3D Printed Case (x1)
